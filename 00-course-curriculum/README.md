# Course Curriculum

The complete Azure Data Engineering program contains **20 subject areas and 100 detailed topics**. This folder is the dedicated home for the master curriculum PDF and curriculum revisions.

## Curriculum

1. Data Engineering Foundations (1–5)
2. SQL for Data Engineers (6–10)
3. Python for Data Engineers (11–15)
4. Azure Cloud Fundamentals (16–20)
5. Azure Storage and ADLS Gen2 (21–25)
6. Azure SQL and Database Integration (26–30)
7. Azure Data Factory Essentials (31–35)
8. Azure Data Factory Advanced (36–40)
9. Azure Synapse Analytics (41–45)
10. Apache Spark Fundamentals (46–50)
11. Azure Databricks (51–55)
12. Delta Lake and Lakehouse (56–60)
13. Data Warehousing and Modeling (61–65)
14. Streaming and Real-Time Engineering (66–70)
15. Microsoft Fabric Data Engineering (71–75)
16. Security and Data Governance (76–80)
17. DevOps and Infrastructure as Code (81–85)
18. Monitoring, Reliability and Optimization (86–90)
19. Enterprise Architecture and Migration (91–95)
20. Production Capstone and Interview Preparation (96–100)

Every subject has five detailed lessons. Conceptual chapters prioritize comprehensive definitions and worked examples; hands-on chapters add relevant labs, synthetic datasets, code, architecture and validation.
