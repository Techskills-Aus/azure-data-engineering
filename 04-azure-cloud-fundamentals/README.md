## Publication standards
Each chapter will receive a detailed, illustrated, original PDF and a well-designed **PowerPoint with at least 15–20 slides**. Use a consistent professional white-background theme, colored headers, diagrams, tables, explanatory callouts, readable typography, slide titles and subtitles, and thoughtful transitions/animations where supported. Use concise bullets only when they improve learning; do not force six or seven bullets onto every slide. Any hands-on labs and datasets must be directly relevant to the topic. Include official Microsoft Learn references and avoid unverified cloud-execution claims.
