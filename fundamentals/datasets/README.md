# Bank posting dataset

Synthetic seed 2718. One delivery per row. posting_id identifies the ledger posting and version specifies the authoritative revision. account_id is an integer in a generated population of 5,000 accounts at the default tier. Each account maps deterministically to NY, IL or TX in a 60/30/10 distribution. business_date spans 2026-01-01 through 2026-03-31. amount_cents is signed USD cents. arrival_batch identifies the ingestion partition; paths use separate batch files. Late first deliveries are 1% of postings, exact replays are 1%, and version-2 corrections are 0.5%. The edge cases are disjoint. The included plain CSVs are the 1,000-row smoke tier. The compressed files contain the full delivery set. See artifacts/Bank Posting Reconciliation - Local Run.txt for measured sizes and counts. Regenerate other tiers using code/bank-posting-reconciliation-lab.py.
